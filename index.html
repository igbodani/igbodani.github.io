Scientific machine learning2023–2024

QUANTICS

Representative sampling for hydrogen adsorption-energy prediction in ternary Ni–Co–Pt alloys. I developed the sampling workflow, selected configurations for collaborators’ energy calculations, and evaluated models using the returned labels.

M.S. thesis · Python package author and maintainer

Methods & contribution

The workflow combines feature scaling, dimensionality reduction, clustering, and representative selection. My contribution connected sample selection to model evaluation using labels from collaborators’ energy calculations.

The studied system was ternary Ni–Co–Pt. QUANTICS is also available as a reusable Python package.

Multimodal AICompleted pilot

Visual-memory reliability

When should a system answer an object-location question, and when should it decline? I built an offline evaluation pipeline using DynaMem code and ran 120 queries across two recorded DynaBench scenes, comparing age-only and age-plus-similarity rules.

Personal research project · Completed October 2026

Pilot findings & limitations

Of 120 queries, 54 were used for development and 66 were held out. A retrospective comparison used the 42 held-out queries with known labels.

At 18 answers each, the age-plus-similarity rule had 1 geometric error versus 2 for age-only. This small, tie-sensitive difference is diagnostic evidence, not a general performance claim.

I also examined frame-cutoff sensitivity and cases where location-based scoring can conceal a wrong-object match. Queries with unknown labels were excluded from correctness scoring.
